## 進捗の色表現(解いた割合の濃淡)

- 決定済み部分: **資格色で統一する**(CD-003)。各アプリの資格色をベースに、解いた割合を濃淡で見せる。
- 内容: 分野・章ごとの「解いた割合」を色の濃淡で見せる表現。
- 状況: **ITパスポートで試行中**(修正 PR は別途進行中)。他アプリへの展開は未定。
- 未確定: 段階数、色以外の手がかり(文字・アイコン併記)、プレミアム扱いの有無、資格色の定義箇所の共通化。
- 守ること: 色だけに頼らない(文字併記)、責める表現にしない、コントラストを満たす。
- 見直し: 他アプリ展開時に、資格色の定義箇所を共通化するか決める。
