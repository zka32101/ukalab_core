# 決定ログの運用

## 現状(確認した事実)

- core の [../DECISIONS.md](../DECISIONS.md) は「## 2026-10 …」のような**日付・テーマ見出し**で末尾追記する形式。
- 「決定38」「決定50」「決定76」「決定77」などの**通し番号**は、各アプリの README・`docs/ui.md`・kit の CHANGELOG から参照されている(例: 決定38=ストーリー型の共通エンジン、決定50=用語カード、決定66=乙4、決定77=資格別テーマ)。
- 通し番号の**正本の置き場所は core / kit / アプリのどのリポジトリにも見当たらない**(企画設計書側にあると思われる)。要確認。
- 登録・課金の決定は `D1〜D10`(別枠)。

## ルール

1. 新しい決定は、このディレクトリの [decision_log.md](decision_log.md) の「記録」に **CD-NNN**(3桁の連番。ここ専用)で末尾に追記する。既存の「決定N」は番号を付け替えず、該当する場合は「関連: 決定N」と書く。
2. 1件につき 日付・背景・決定・影響アプリ・見直し条件 を書く。決めた人(ユーザー/運営者)と、推奨案を承認したのか自分で決めたのかも一言。
3. 既存の決定を変えるときは、古い項目を消さず「CD-NNN で変更」と追記する。
4. 数値・価格・ID・タグは、書く前にリポジトリで確認する。確認できなければ「要確認」。
5. 個人名・Drive URL・メールアドレス・実キーは書かない。
6. 決定ログだけの PR は docs のみ。コード・pubspec・タグは触らない。

## 雛形

```markdown
### CD-NNN タイトル(YYYY-MM-DD)
- 背景:
- 決定:
- 決定者: ユーザー / 運営者(推奨案を承認 / 自ら指定)
- 影響アプリ: 全アプリ / 〇〇, △△
- 関連: 決定N / D# / PR #
- 見直し条件:
```

### CD-006 bike の対応言語は日本語と英語の2言語に絞る(2026-10-23)
- 背景: bike は UI 文言のみ5言語(ja/en/zh/vi/pt、arb 各92キー)で、問題文・選択肢・解説は日本語のみ。外国語に対応するのはホーム周りの7画面のみで、設定・模擬試験・標識クイズは日本語のままの混在状態だった。需要の根拠がリポジトリに無く、問題文翻訳(3,920問)は誤訳が誤学習に直結し、専門確認の体制も無い。
- 決定: 対応言語は ja と en の2言語に絞る。zh/vi/pt の arb と関連設定は編入 PR で整理する(AppLocalizations の呼び出しの扱いも編入 PR で設計)。CD-005 の「多言語(5言語)は現状維持」はこの決定で置き換え。
- 未決事項: 問題文・選択肢・解説の英訳。現状は日本語のみで、英語端末では UI だけ英語になる混在が残る。問題文の英語対応の要否・範囲は別途決定が必要。翻訳する場合は AI 下書き+専門確認とし、日本語を正とする。
- 決定者: ユーザー
- 影響アプリ: bike
- 関連: CD-005 / [new_app_checklist.md](new_app_checklist.md) の「既存アプリを編入する場合」
- 見直し条件: 問題文の英語対応の方針が決まったとき。外国人受験者の需要が確認でき、翻訳の専門確認体制が整ったとき。

### CD-007 bike は広告を使う(ホームのバナー広告を残す)(2026-10-23)
- 背景: bike の README は「バナー広告は方針上不採用(`canShowBanner` は常に false)」と書いていたが、実装は `home_view.dart` で `adGate.banner(BannerPlacement.home)` を使っており、文書と実装が矛盾していた。
- 決定: バナーは使う(ホームのバナーを残す)。
  - 出題中・ひっかけ道場ボス戦中・合格予測メーター直後は広告表示禁止。`AdGateService` の禁止ゾーンは維持する。
  - インタースティシャルは1日ノルマ完走後の結果画面のみ・1日1回(既存方針)。
  - 広告は `noads`(¥480)で非表示にできる。
  - 広告ユニットIDと AdMob App ID はコードに直書きせず、`--dart-define` / CI Secrets で注入する(D9)。
  - UMP 同意メッセージの作成は運営作業。
  - 対象年齢は13歳以上を想定(子ども向けではない)。
- 決定者: ユーザー
- 影響アプリ: bike(README の「バナー不採用」記述の修正、`AdUnitIds` のバナーID必須化)
- 関連: CD-004 / CD-005 / [new_app_checklist.md](new_app_checklist.md)
- 見直し条件: 広告収益・レビュー評価を見て判断。
- 補足(2026-10-24): bike のノルマ(1日の学習目標)終了時インタースティシャルは許容する(問題・ボス・予測メーターの領域外)。ストア文書(掲載文・データセーフティ・ポリシー)はホームのバナー+ノルマ終了時インタースティシャルの記載に揃える。なお実装の頻度は `AdGate` 既定(最短3分間隔・1日5回まで)で、上の「1日1回」とは差がある(今回は決定を変更せず、事実のみ記録)。noads/premium 購入中は広告を出さない。
