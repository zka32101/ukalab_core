決定日: 2026-10-20。納品範囲の変更（同日）: 画像は A（必須13枚）+ C（小物 2〜3枚）を作り、B（推奨23枚）は作らない。
`docs/qualification_mascot_spec.md`「決定事項（案B）」に基づく。
状態: 画像制作セッションへそのまま渡せる指示書。ドキュメントのみで、コード・pubspec・assets は変更しない。
サーキ（`circa`、ITパスポート）の詳細は spec §8 の引継ぎ文を使う。ここでは概要のみ載せる。

画像総数の見積もり（A+C）: サーキ 16枚（A13 + C3）。新規6体（ノーダ・シェル・ヒラリ・ソロ・サラ・タツ）は各 15〜16枚（A13 + C2〜3）で、6体計 90〜96枚。合計 106〜112枚。

共通ルールは §1、キャラ別の指定は §2、アプリがまだ無い資格は §3 に一覧だけ載せる。

### 1.3 形式と容量

- 形式: webp（RGBA）、背景は透明。縁の白いふちを残さない。キャラが画像の端で切れない。
- 容量の目安: icon・Lv・special は1枚 40KB 以下、scenes・guide は 150KB 以下、states・poses・items は 60KB 以下。1体の A+C で 1MB 以下（B を作らないため。B を作る場合は 1.5MB 以下）。
- メタデータは削除して納品する。

### 1.4 ファイル命名規則

- 小文字・英数字・アンダースコアのみ。拡張子は `.webp`。
- 形式: `<キャラid>_<要素>.webp`。キャラid が先頭に付く。サブフォルダは `scenes/` `states/` `guide/` `poses/` `items/`。
- 配置先: `assets/mascot/<キャラid>/`。納品は `<キャラid>/` フォルダを1つの zip にまとめる。
- 小物名は英小文字（例: `sala_flask.webp`）。

### 1.5 画風

- 少しかわいらしいタッチ: 丸みのあるシルエット、やわらかい線、やさしい表情、3頭身前後。
- 成人向けアプリなので、子ども向けに寄せすぎない（大きすぎる目、過度に幼い顔、幼児向けの色使いを避ける）。
- 作業前に既存4体（kai, mio, moka, mike）とサーキの Lv1〜5 を見て、画風・線の太さ・彩度を確認し、大きく乖離しない範囲にする。
- 既存4体の主色（目視の概算）: kai=水色〜ミント #8EBFC3、mio=コーラル #F0897A、moka=クリーム #EAD9A8（差し色は濃いティール #2E9A8C）、mike=グレー〜白 #B0B5B8（差し色はサーモン #F29C91）。

### 1.6 禁止事項（全キャラ共通）

- 実在団体（試験団体、省庁、協会、企業）の公式ロゴ・紋章・マーク、およびそれらの配色の再現を使わない。
- 「公式」「認定」「提携」「推奨」を思わせる表現・意匠（認定印、メダルの文言、団体名の表記など）を使わない。
- 「合格保証」「必ず受かる」「絶対合格」などの保証表現、またはそう読める小道具・文字を入れない。
- 個人情報を入れない。実在の人物の顔・名前、個人名、署名、アカウント情報、共有ドライブのURL、キー類を、画像・メタデータ・ファイル名・納品メモに含めない。
- 画像内に文字、数字、ロゴ、透かしを入れない（資格名の文字も入れない）。
- 既存の著名キャラクター（企業マスコット、ゲーム・アニメのキャラ）に似せない。各キャラの個別注意は §2。

### 1.7 納品メモ（zip に同梱）

使ったAI画像生成サービス名、作成日、「全画像がAI生成である」旨、スタイル固定文、決めた色（16進数）、各画像のプロンプト、枚数、チェックリストの結果。サービスの規約確認はオーナー側で済み（再確認は不要）。

### 1.8 同一キャラを保つ手順

spec §4.2 に従う。キャラシート（正面・横・背面の全身、顔アップ、normal/joy）を最初に決め、Lv3 → Lv1 → Lv5 の順に作る。normal と joy は同じ画像から表情だけ変える。Lv が変わっても変えない特徴を3〜4点固定する。

## 4. 納品チェックリスト（各キャラ共通）

- [ ] フォルダ名・ファイル名が §1.2・§1.4 と完全一致（小文字、`.webp`）
- [ ] 枚数: サーキ = A 13 + C 3 = 16枚。新規6体 = A 13 + C 2〜3 = 15〜16枚（B は作らないため含めない）
- [ ] 全ファイルが webp、RGBA、背景が透明（縁の白いふちなし）
- [ ] サイズが §1.2 のとおり（icon は 256x256）、容量が目安以内
- [ ] Lv1〜5 で同一キャラと分かり、成長が分かる。normal と joy は表情のみ違う
- [ ] 既存4体・サーキ・他の資格キャラと並べて見分けがつく（主色・シルエット）
- [ ] 画像内に文字・数字・ロゴ・「公式」「認定」表記・合格保証表現・署名・透かしがない
- [ ] 実在団体の公式ロゴ・著名キャラ・実在人物に似ていない
- [ ] 個人名・URL・アカウント情報・キー類が、メタデータ・ファイル名・メモにない
- [ ] 納品メモがある（§1.7）
