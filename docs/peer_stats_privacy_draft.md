# 匿名集計（peer stats）プライバシー・ストア申告 下書き

> **下書きです。公開・申告は、人が内容と実装を確認してから行う。** 法的助言ではない。送信を有効にした版を出す前に、リリース担当が実装・Firebase の設定と突き合わせる。年少者向けアプリは各ストアの子ども向けポリシーを特に確認する。
> 実装の根拠: `docs/peer_stats.md`、決定: `docs/DECISIONS.md`（2026-10-15）。

## 1. 送る・集める情報（事実の整理）

| 項目 | 内容 |
|---|---|
| 送る値 | ランダムな匿名 ID（installId）、日付（日本時間）、連続学習日数、延べ回答数、試験日（任意） |
| 送らない値 | 名前、メール、Firebase Auth の uid、広告 ID、端末固有 ID、位置情報、回答内容 |
| 送る条件 | 利用者が「参加する」をオンにした場合のみ（既定オフ）。年少者向けは保護者ゲート通過後のみ |
| 頻度 | 1 日 1 回まで |
| 保存先 | Google Cloud Firestore（東京リージョン）。端末の値は他の利用者に見えない |
| 表示 | 集計（人数・合計・中央値・分布）のみ。100 人を超えるまで表示しない |
| 保存期間 | 60 日以上更新がない端末の値は自動的に集計から外れ、削除される |
| 削除 | アプリの設定で参加をやめ、削除を依頼できる（installId を指定して削除） |
| 結び付け | installId は他のデータ（uid・購入情報など）と結び付けない |

## 2. プライバシーポリシー追記案（日本語）

> ### 匿名の学習状況の集計について
> 本アプリには、他の利用者の学習状況（「今日学習した人の数」「みんなの累計問題数」など）を表示する機能があります。この機能に**参加するかどうかは利用者が選べ、初期設定では参加しません**（参加しなくても集計の表示は見られます）。
>
> 参加すると、1 日 1 回まで、次の情報をランダムに作られた匿名の ID とともに当社のサーバー（Google Firebase）に送信します。連続学習日数、延べ回答数、試験日（設定している場合）、学習した日付。氏名、メールアドレス、位置情報、広告 ID、端末を識別する情報、回答の内容は送信しません。この ID はアプリ内で作られるもので、他の情報と結び付けず、個人を特定するために使いません。
>
> 送信された情報は、人数・合計・中央値・分布といった集計値を作るためだけに使い、他の利用者に個別の値は表示しません。集計値は、対象が 100 人を超えるまで表示しません。60 日以上更新のない情報は自動的に削除します。
>
> 設定からいつでも参加をやめられます。参加をやめたあとのデータの削除は、アプリ内の案内（または［問い合わせ先］）から依頼できます。アプリを削除した場合も、情報は一定期間後に自動で削除されます。
>
> **お子さまが利用する場合**: 参加には保護者の確認（保護者ゲート）が必要です。

## 3. 保護者・子ども向けの配慮

- 参加は**保護者ゲートを通した場合のみ**。通さない場合は表示のみで、送信しない。
- 子どもに見せる文言は、他者と比べて落ち込ませない表現にする（上位半分のときだけ順位を表示、既存の `PeerStatsStrings`）。
- 個人を特定できない設計: 100 人以下の区分は集計に含めない／端末の値は読めない／installId は他データと結び付けない。
- 第三者への提供・広告への利用は行わない。

## 4. Apple App Store「App のプライバシー」申告案

送信を有効にして配備する版から。**最終判断は申告の担当者。**

| データの種類 | 収集 | 用途 | ユーザーに関連付け | トラッキング |
|---|---|---|---|---|
| 使用状況データ → 製品の操作（連続日数・延べ回答数・日付） | あり | アプリの機能（他の利用者への集計表示） | **関連付けない**（installId はアカウント・購入と結び付けない） | **しない** |
| 識別子 → デバイス ID（installId。端末の識別子ではなくアプリが作るランダム ID） | あり（申告上は保守的に「あり」） | アプリの機能 | 関連付けない | しない |

- 備考: 参加は任意（オプトイン）。子ども向けカテゴリのアプリは、第三者の分析・広告 SDK の制約が厳しい。Firebase（Firestore / Functions / App Check）の利用が子ども向けカテゴリの規約に合うか、配備前に確認する。
- 送信を有効にしない版（フラグ false）では、この項目の追加は不要。

## 5. Google Play「データセーフティ」申告案

| 項目 | 回答案 |
|---|---|
| アプリのアクティビティ（アプリ内の操作） | 収集する。用途: アプリの機能。**第三者と共有しない**。暗号化して送信（HTTPS）。**任意**（利用者が参加を選ぶ） |
| デバイスまたはその他の ID | 収集する（アプリが作るランダムな ID）。用途: アプリの機能。共有しない。任意 |
| データの削除 | ユーザーが削除をリクエストできる（アプリ内の手順。60 日で自動削除） |
| 子ども向けポリシー（ファミリー） | 対象アプリは、参加に保護者ゲートが必要である点と、広告 ID を使わない点を確認 |

## 6. データ削除の手順（運用）

1. 利用者: アプリの設定で参加をオフにする（以降は送信しない）。
2. 削除を希望する場合: アプリの「データを削除」から `erasePeerStats`（installId 指定の callable。App Check 必須）を呼ぶ。端末内の installId は削除後に破棄する。
3. アプリを削除しただけの場合: installId を知る手段が無くなるため個別削除はできないが、60 日以上更新が無ければ集計から外れ、日次ジョブが物理削除する。
4. 問い合わせ対応（installId を提示できない場合）: 個人を特定できないため、個別の削除はできない旨と 60 日で自動削除される旨を案内する。
