# 実機確認チェックリスト（うかラボ5アプリ共通）

CI・ウィジェットテストでは確認できない、実機でだけ見られる項目のリスト。リリース前に、下の「共通」と該当アプリの「アプリ別」を上から順に確認する。

対象アプリ: 漢検(kanken) / G検定(ukalab-g-kentei) / 生成AIパスポート(ukalab_seisei_ai_passport) / 簿記3級(ukalab_boki) / 危険物乙4(ukalab_otsu4)

## 0. 準備

- 端末: 小画面（幅 320〜360dp 級）と標準（幅 412dp 級）の Android 各1台以上。可能なら iPhone SE 級と大きめの iPhone も
- 設定の組み合わせ: ライト／ダーク、文字サイズ 標準／最大、表示サイズ 標準／最大、システム言語 日本語
- ビルド: 実際にストアへ出す署名・難読化設定のリリースビルド（デバッグビルドでは速度・課金・広告の挙動が違う）
- 課金: RevenueCat のサンドボックス（Android はライセンステスター、iOS は Sandbox Apple ID）を用意
- 各項目は 結果（OK / NG / 該当なし）・端末・OS・日付を残す。NG はスクリーンショットか画面録画を付ける

## 1. ホーム画面の再構成（共通）

- [ ] 幅 320dp 級でカード・ボタン・見出しが欠けない、はみ出しの黄黒ストライプが出ない、横スクロールが出ない
- [ ] 2列グリッドのタイル幅が揃い、タイトルが2行までで省略される（3行以上で潰れない）
- [ ] 余白が詰まりすぎず、タップ領域が 48dp 以上ある（指で隣のタイルを誤タップしない）
- [ ] 文字サイズ最大でも、ボタン文言が見切れない・ボタンの高さが文字に追従する
- [ ] 表示サイズ最大＋文字最大の組み合わせでホームが縦にスクロールして最後まで届く
- [ ] ダークテーマで背景と文字のコントラストが十分（淡色文字・無効状態のボタン・区切り線が見える）
- [ ] 正誤は色だけでなく ✓／✕ と文言でも伝わる（success 色は文字としては AA 未満。docs/ui.md 参照）
- [ ] ノッチ／パンチホール／ジェスチャーバーに被らない（SafeArea）、横向きに回しても崩れない
- [ ] 画面の戻る操作（Android 戻るボタン／ジェスチャー、iOS スワイプ）で想定の画面に戻る。ホームで戻るとアプリが閉じる
- [ ] 推し・衣装・コインの表示（ヘッダー等）が画像の読み込み前後でガタつかない

## 2. 学習画面（共通）

- [ ] 問題文が長い・選択肢が長いときに折り返して読める（小画面・文字最大）
- [ ] 解説・数式・図が端末幅に収まる（拡大／スクロールできる）
- [ ] 回答後のフィードバック（効果音・振動）の ON/OFF が設定どおり動く
- [ ] 途中でアプリを閉じて再開すると、進捗・コイン・復習キューが保たれる
- [ ] 機内モードで起動・学習できる（オフライン前提の機能が通信待ちで固まらない）

## 3. ながら学習（音声）

- [ ] 画面をロックしても音声が止まらない（または仕様どおり止まる）。ロック画面／通知シェードの再生・一時停止が効く
- [ ] 他アプリへ切り替え（バックグラウンド）後の再生継続・復帰が仕様どおり
- [ ] 音声の一時停止 → 再開で続きから読む。早送り・戻しの位置が合っている
- [ ] 着信・他アプリの音声・アラームが割り込んだとき、一時停止して終了後に自動復帰または手動復帰できる
- [ ] イヤホン抜き・Bluetooth 切断で一時停止する（スピーカーから突然大音量で鳴らない）
- [ ] マナーモード／消音スイッチ時の挙動（iOS）、メディア音量が 0 のときの案内
- [ ] 読み上げの言語・速度・声が端末ごとに破綻しない（TTS 未導入端末でのエラー表示）
- [ ] 長時間（30分以上）再生してもクラッシュ・発熱・電池の異常消費がない

## 4. 通知

- [ ] 初回の通知許可ダイアログが、意味の伝わる場面で出る（起動直後に唐突に出ない）。拒否してもアプリが使える
- [ ] 学習リマインドが設定した時刻に届く（Android 13+ の権限、iOS の通知設定、省電力モード、Doze 下）
- [ ] 通知をタップすると想定の画面を開く（コールドスタート／バックグラウンドの両方）
- [ ] 時刻・オン／オフ変更後に古い通知が残らない。再起動・端末再起動後も予約が復元される
- [ ] 通知の文言が子ども向け・過度な煽りでない。アプリ名・アイコンが正しい
- [ ] 通知のチャンネル（Android）がアプリの設定画面から個別にオフにできる

## 5. 課金（RevenueCat サンドボックス）

- [ ] 商品名・価格・期間・自動更新の表記がストアの表示（ローカライズ済み価格）と一致する
- [ ] 購入 → 即座にプレミアムが解放される。購入後すぐにアプリを再起動しても維持される
- [ ] 購入のキャンセル（ユーザー操作）でエラーダイアログを出さず、元の画面に戻る
- [ ] 支払い保留・失敗・オフライン時の案内が出て、二重請求にならない
- [ ] 購入の復元で別端末／再インストール後に権利が戻る。購入履歴がないときは案内を出す
- [ ] 期限切れ（サンドボックスは更新が短い）後に権利が外れ、無料機能に戻る。再購入できる
- [ ] 返金／キャンセル後の権利剥奪（Entitlement の失効）が反映される
- [ ] 利用規約・プライバシーポリシー・購読の管理（解約方法）へのリンクが開く
- [ ] 機内モードで起動したときに、直前の購読状態をキャッシュで保てる（無料に落ちない）
- [ ] 本番キーとサンドボックスキーを取り違えていない（リリースビルドの API キー）

## 6. 広告・同意（UMP／ATT）

- [ ] 初回起動で同意フォーム（UMP）が地域に応じて表示される。「同意しない」でも使える
- [ ] iOS の ATT 許可ダイアログの文言と表示タイミングが適切。拒否時に非パーソナライズ広告になる
- [ ] 同意の再設定（プライバシー設定）の入口があり、変更が反映される
- [ ] プレミアム購入者に広告が出ない。無料ユーザーの広告が学習の操作（回答ボタン等）に被らない
- [ ] 広告の読み込み失敗・オフライン時にレイアウトが崩れない（空白が残らない）
- [ ] テスト広告 ID でなく本番の広告 ID になっている（ただし自分の端末では自己クリックしない）

## 7. 親ゲート（子どもが使う場合）

- [ ] 外部リンク・課金・設定変更・問い合わせの前に親ゲートが出る
- [ ] ゲートの設問が小学生に解きにくく、大人には簡単。毎回内容が変わる
- [ ] 誤答を繰り返すと待機時間が入る／閉じてもゲートを回避できない
- [ ] 文字拡大・ダークテーマでゲートが読める

（該当するアプリのみ。対象外のアプリは「該当なし」）

## 8. データセーフティ・プライバシー

- [ ] ストア申告（Google Play のデータセーフティ／App Store のプライバシーラベル）が、実際の収集（広告 ID・購入情報・クラッシュ・分析）と一致する
- [ ] 通信を観察して（プロキシ等）、申告にない個人情報を送っていない
- [ ] アプリ内のプライバシーポリシーのリンクが開く。ストア掲載の URL と同じ
- [ ] アカウント／データ削除の導線（ある場合）で実際に消える。アンインストール後に再インストールしたときの状態が仕様どおり
- [ ] 共通アカウント同期（Firestore）を使う場合、ログアウト・端末移行・機内モード復帰で矛盾しない
- [ ] 非公式アプリである旨の表記（G検定・簿記・乙4・漢検・生成AIパスポートの各主催団体と無関係）がストア文面とアプリ内にある

## 9. 起動速度・安定性・端末負荷

- [ ] コールドスタートからホーム表示まで（目安: 低スペック端末で 3 秒以内）。スプラッシュで固まらない
- [ ] 問題データ読み込み（初回／2回目以降）で白画面が長く出ない
- [ ] 学習中のスクロール・画面遷移がカクつかない（低スペック端末）
- [ ] 30分連続使用でメモリ増加・発熱・電池消費が異常でない
- [ ] 画面回転・分割画面・バックグラウンド復帰でクラッシュしない
- [ ] 初回起動（インストール直後）／アップデート後の初回起動（旧データ移行）の両方で動く
- [ ] リリースビルドのアプリサイズが前回から極端に増えていない

## 10. ストア提出前

- [ ] バージョン名／ビルド番号がストアの最新より大きい
- [ ] スクリーンショットが現行 UI と一致（ダーク版が必要な場合は用意）
- [ ] 最小 OS バージョン（minSdk／iOS 最小）の端末で起動する

## アプリ別の追加項目

### 漢検（kanken）

- [ ] 書き取り・筆順・手書き入力がある画面で、指／スタイラスの描画が追従し、拡大でも崩れない
- [ ] 漢字フォント（常用外・旧字・異体字）が端末のフォント差で豆腐（□）にならない。縦書き表示の折り返し
- [ ] 級（10級〜1級）の切替で問題・進捗・コインが混ざらない
- [ ] 読み・部首・四字熟語など形式別の入力（IME／日本語キーボード）で変換候補が問題を隠さない
- [ ] 画像・図を使う問題がダークテーマで見える

### G検定（ukalab-g-kentei）

- [ ] 用語・略語が長い問題文が小画面で読める（英字略語の折り返し）
- [ ] 用語集・学習ラボなど、検索入力があれば IME とキーボードで入力欄が隠れない
- [ ] 模擬試験のタイマー（バックグラウンド・画面ロック中の経過、復帰後の残り時間）
- [ ] 「JDLA とは無関係の非公式アプリ」の表記がストア文面とアプリ内にある

### 生成AIパスポート（ukalab_seisei_ai_passport）

- [ ] 生成AIパスポート（GUGA）と追加モジュール（GAIP）の切替で、問題・進捗が混ざらない
- [ ] AI の用語・プロンプト例など長文が小画面で読める。コピー操作ができる場合は選択・コピーが動く
- [ ] 最新情報の注意書き・非公式表記が表示される

### 簿記3級（ukalab_boki）

- [ ] 仕訳入力・元帳・伝票・精算表などの表形式 UI が、幅 320dp 級で横スクロール／拡大で操作できる（セルがタップしづらくない）
- [ ] 数字キーパッド／カンマ表示／金額入力で、IME・ソフトキーボードが入力セルを隠さない
- [ ] 勘定科目の選択リストが小画面でも選べる（検索・スクロール）
- [ ] ハンズフリー（ながら学習）と音声読み上げ（hands_free／nagara）の項目 3 を重点確認
- [ ] 模擬試験（制限時間）のタイマーとバックグラウンド復帰
- [ ] 推し（oshi）・衣装・コインの表示と購入、課金後の解放
- [ ] 起動処理（startup）での初期化が低スペック端末で長引かない

### 危険物乙4（ukalab_otsu4）

- [ ] 乙1〜乙6 の種別切替で問題・進捗が混ざらない
- [ ] 化学式・指数・単位（下付き／上付き）が小画面・文字最大で崩れない
- [ ] 物質の性質表・図が横に収まる（または横スクロールできる）
- [ ] 科目別の合格基準（各科目 60% 以上など）の表示が正しい
- [ ] 危険物の写真・図がダークテーマで見える
